# MYVCS

This is an educational project to understand the internal workings
of git by recreating / reverse engineering it. 

it is not a fork of git or any other project, all code is written by the author
with AI tools used for learning and researching.

## Implemented commands

- [x] hash-objects
- [x] cat-file
- [x] ls-files 
- [x] write-tree
- [x] add
- [x] commit
- [ ] log
- [ ] checkout
- [ ] status
- [ ] merge
- [ ] push
- [ ] pull    

## Dependencies

- ZLIB for compression
